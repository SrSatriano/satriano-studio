Política de Privacidade

Última atualização: 29 de outubro de 2026

O Satriano Studio Upload é uma ferramenta pessoal usada somente por Matheus Rodrigues Satriano para publicar vídeos nos próprios canais do YouTube.

1. Uso dos Serviços de API do YouTube

Esta ferramenta usa os Serviços de API do YouTube. Ao usá-la, você concorda com os Termos de Serviço do YouTube. A Política de Privacidade do Google também se aplica.

2. Dados acessados

Com a autorização do dono do canal pelo Google (OAuth), a ferramenta acessa apenas o necessário para publicar: os vídeos e playlists do próprio canal e o envio de novos vídeos com título, descrição, tags, categoria, miniatura e data de publicação. Ela não lê comentários, mensagens, dados de espectadores nem dados de outros canais.

3. Como os dados são usados

Os dados servem só para enviar e agendar vídeos e para evitar enviar o mesmo vídeo duas vezes. Não são vendidos, compartilhados com terceiros nem usados para publicidade.

4. Armazenamento

O token de acesso do Google e um registro local dos envios (identificador do vídeo e data agendada) ficam apenas no computador do autor. Nenhum dado é armazenado em servidores. Dados obtidos da API não são guardados por mais de 30 dias sem serem atualizados.

5. Revogação e exclusão

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Ao revogar, ou a pedido pelo e-mail abaixo, os arquivos locais ligados àquela conta são apagados em até 7 dias.

6. Contato

mat.satriano@gmail.com

Privacy Policy

Last updated: October 29, 2026

Satriano Studio Upload is a personal tool used only by Matheus Rodrigues Satriano to publish videos to his own YouTube channels.

1. Use of YouTube API Services

This tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. The Google Privacy Policy also applies.

2. Data accessed

With the channel owner's authorization through Google (OAuth), the tool accesses only what is needed to publish: the channel's own videos and playlists, and uploading new videos with title, description, tags, category, thumbnail and publish date. It does not read comments, messages, viewer data or other channels' data.

3. How data is used

Data is used only to upload and schedule videos and to avoid uploading the same video twice. It is not sold, shared with third parties or used for advertising.

4. Storage

The Google access token and a local upload log (video ID and scheduled date) are stored only on the author's computer. No data is stored on servers. Data obtained from the API is not kept for more than 30 days without being refreshed.

5. Revocation and deletion

Access can be revoked at any time at myaccount.google.com/permissions. On revocation, or on request via the e-mail below, local files linked to that account are deleted within 7 days.

6. Contact

mat.satriano@gmail.com
